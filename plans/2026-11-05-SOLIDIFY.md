## Context

Babillard is mature (1 607 commits, 348 tsx / 368 ts, 29 185 lines CSS, 2 500+ unit tests, 175 e2e specs, ~30 build-gating guards). STATE.md says "no open box" — the backlog is empty by ledger. Three read-only audits (components/CSS, flows/UX, tests/guards) run 2026-11-05 and spot-checked against code found that the **drift the guards don't cover** is where the app is uneven: the same concept built 2–6 ways, prose rules with no test, flows that differ by section, docs whose cells no test derives.

Owner decisions (2026-11-05): fix the audited flow bugs in-plan (each with a guard) · add **oxlint**, CI-gated · docs truth in scope, test-derived · **scope-complete, not time-boxed** ("doesn't matter the number of days, all identified must be completed"). No business-logic change beyond those bugs.

Honest estimate: 9 waves, ~42 working days. Durations are estimates, not cut-offs.

## Standing rules every wave inherits (CLAUDE.md — not repeated per item)

- **Plant every new guard red** via an exact-match Edit (never `sed`), read the red output to confirm the planted line is the one named, revert, re-run green; the commit message names the plant. Every ALLOWED/ratchet list gets the stale-entry check (copy `chip-rule.test.ts:112`).
- **Grep the claim before building** — audit counts are from a moment.
- New shared component → `src/pages/DevKit.tsx` specimen + `COMPONENTS.md` row + CLAUDE.md primitive-table row (`devkitParity.test`; mind `docCounts` 700-line cap on CLAUDE.md — swap a row in, prune a sentence out).
- `src/styles/styles.css` `@import` — append only.
- `STATE.md` §3 entry + §1 numbers in the same commit as each wave.
- Push to `main`. Waves marked **[machinery]** run the affected shards `npx playwright test --workers=1 --retries=0 <specs>` locally, push, and wait for the CI E2E job to be green before the next commit (the full suite OOMs on this machine — STATE §1).

- Guard vocabulary: **fail-closed+ALLOWED(reason)** = 0 tolerance, exceptions are a `Map<file, reason>`; **ratchet** = pinned integer, only falls, lowered in the sweep's own commit (`glossary`/`aria-label-rule` shape); **inventory** = every discovered site must be classified (`layer-order` shape).
