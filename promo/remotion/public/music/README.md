# Music

Drop a calm, royalty-free track here (e.g. `calm.mp3`) and set `music: 'calm.mp3'`
on the script in `promo/scripts/<id>.ts`. The capture rig copies that filename into the
manifest, and `PromoVideo` plays it at low volume (0.22) under the whole video.

Audio files are gitignored (licensing) — only this note is committed. Sources: the
YouTube Audio Library, Pixabay Music, or a licensed track you own.
